## 🛠️ CÔNG NGHỆ SỬ DỤNG
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS), Figma (UI Prototype).
* **Backend:** C++ Core (OOP Architecture, API HTTP/REST).
* **Database:** MySQL Database (Chuẩn 3NF, InnoDB Transaction Engine).
* **Công cụ phân tích:** draw.io (UML Diagrams, ERD).

---

## 📂 CẤU TRÚC THƯ MỤC DỰ ÁN
* `index.html`, `pages/`, `css/`, `js/`: Mã nguồn giao diện người dùng (Frontend Web).
* `database/`: Mã nguồn SQL tạo bảng CSDL (`init_schema.sql`) và dữ liệu thử nghiệm (`seed_data.sql`).
* `backend/`: Mã nguồn logic xử lý C++ Core và thiết kế API.
* `docs/`: File báo cáo Tiểu luận (.docx) và sơ đồ thiết kế gốc (.drawio).
